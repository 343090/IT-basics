# Portfolio — Eymen Uzun

Persoonlijke portfolio-website van **Eymen Uzun**, Software Developer student.

## Over dit project

Deze website dient als online portfolio om mijn vaardigheden, vakken en projecten te presenteren. Gebouwd met puur HTML, CSS en JavaScript — zonder frameworks.

## Functies

- **Responsive design** — werkt op desktop, tablet en mobiel
- **Hamburger menu** — navigatie op kleine schermen
- **Hero sectie** — welkomstbericht met oproep tot actie
- **Over mij** — persoonlijke info en vaardigheden (HTML, CSS, JavaScript)
- **Vakken** — overzicht van de vakken die ik volg:
  - IT-basics
  - Project (Local WP)
  - Project Management
- **Projectenpagina** — eigen pagina (`projecten.html`) met alle projecten als kaarten, inclusief technologieën
- **Contactformulier** — naam, e-mail en bericht versturen
- **Sticky navbar** — navigatie blijft zichtbaar bij scrollen

## Technologieen

| Technologie | Doel |
|-------------|------|
| HTML5       | Structuur van de pagina |
| CSS3        | Styling en responsive layout |
| JavaScript  | Interactiviteit (menu, formulier) |
